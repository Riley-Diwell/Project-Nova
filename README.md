# Project Nova

**Nova** is a wearable peripheral that lets university students handle everyday
digital interactions - notifications, notes, navigation - without pulling out
their phone.

Landing page: **[projectnova.base44.app/Landing](https://projectnova.base44.app/Landing)**

## Concept

Every interaction Nova handles is judged against three pillars:

- **Attention** - does it cost less focus than the phone equivalent?
- **Agency** - does the user stay in control, with every default overridable?
- **Privacy** - is data kept local-first wherever possible?

The core design metric is **Attention Cost**: any interaction performed on
Nova must cost less attention than doing the same thing on a phone, at the
same if not higher standard of outcome.
